## 👋 Sobre mí

Vengo del control de gestión y las finanzas, donde durante más de una década he trabajado transformando información financiera y operativa en indicadores de gestión, presupuestos, KPIs y cuadros de mando.

He gestionado presupuestos de hasta **100M€** en compañías como **Repsol** y **Red Eléctrica de España**, desarrollando una visión de negocio que actualmente aplico al mundo del dato.

Mi objetivo es combinar **conocimiento de negocio + análisis de datos + automatización** para transformar datos en información útil para la toma de decisiones.

Actualmente estoy completando un **Máster en Data Analytics**, con finalización prevista en diciembre de 2026.

## 📊 Proyectos destacados

### 🧾 Modelo de partes de trabajo — Costes e ingresos

Modelo de datos construido para automatizar el cálculo de **costes de nómina e ingresos** a partir de partes de trabajo.

El proyecto utiliza Power Query y Power Pivot para la transformación y modelado de los datos, junto con medidas DAX para realizar los cálculos automáticamente.

**Tecnologías**

`Power Query` `Power Pivot` `DAX`

---

### 💼 Análisis del mercado laboral Tech

Proyecto de análisis end-to-end sobre el mercado laboral tecnológico.

El proceso incluye:

- Obtención de datos mediante Python.
- Limpieza y transformación del dataset.
- Preparación y unión de tablas.
- Transformación mediante Power Query.
- Uso de MCP dentro del proceso de transformación.
- Análisis de tendencias en puestos de trabajo Tech.

**Tecnologías**

`Python` `Power Query` `MCP`

> 🚧 Proyecto en curso — se actualizará con los resultados finales del análisis.
